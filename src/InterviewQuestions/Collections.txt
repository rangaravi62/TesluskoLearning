-> Q. How Hashmap works internally ?
hashmap works on the principle hashing, hashing is a process where the key is converted into fixed size numerical value, hashcode.
this hashcode is used to determine the index of the bucket in the hashmap where the value will be stored.

internally hashmap uses array of Node objects
class Node<K,V> {
int hash,
K key,
V value,
Node<K,V> next
}

hashcode is generated using the hashcode() method of the object.
in case of collisions, hashmap uses linked list to store the values at each index, collision occurs when two different keys generate the same hashcode.`
in case of collisions, if many entries comes to the same bucket then red-black tree will be used for further optimization
Note : if a bucket reaches the size of 8 in case of collisions then the linked list is converted into red-black tree

put method working ->

when put is called with key and value, the hashcode for key is generated using hashcode() method,
then in that location the key and value are wrapped into Entry object and stored in that bucket.

get method working ->

when get is called with key, the hashcode for key is generated using hashcode() method,
then in that location the linked list is traversed to find the key by using key's equals method, if found then the value is returned else null is returned.


Time Complexity ->
Average case (no or few collisions): Access -> O(1), insertion -> O(1), deletion -> O(1)
Worst case (high collisions): Access -> O(n), insertion -> O(n), deletion -> O(n)
Optimized worst case (Red-Black tree) : Access -> O(logn), insertion -> O(logn), deletion -> O(logn)

-> Q. What is Hashmap Class in Java ?

HashMap is a class in Java that implements the Map interface.
it stores the values in the form of key-value pairs.
keys are unique and values can be duplicate.
one null key is allowed
doesn't maintain the insertion order, for ordering we can use LinkedHashMap
not synchronized, for synchronization we can use ConcurrentHashMap

load factor is a parameter which will be used to decide when to increase the size of the hashmap.
default load factor is 0.75, which means when the size of the hashmap reaches 75% of the capacity then the size of the hashmap will be increased.
load factor = no of entries / capacity

-> Q. Is Hashmap thread safe in Java ?
No, Hashmap is not thread safe, for thread safety we can use ConcurrentHashMap.
we can use Collections.synchronizedMap() to make any map thread safe.

-> Q. Explain changes in Hashmap in Java 8 ?
Before java 8 when there were many collisions at a particular bucket then that bucket used to contain a linked list of entries.
but in java 8 when the size of the linked list reaches 8 then the linked list is converted into a red-black tree for further optimization.

-> Q. How to retrieve value if 'two object keys' have same hashcode ?

If two object keys have the same hashcode, the HashMap will store them in the same bucket as a linked list.
When retrieving a value, the HashMap will iterate through the linked list and use the equals() method of key's to find the correct key.

-> Q. What is difference between fail-fast and fail-safe iterators ?
Fail fast iterators throw ConcurrentModificationException if the collection is structurally modified while iterating over it.
ex : ArrayList, HashMap, HashSet
Fail safe iterators don't throw any exception if the collection is modified while iterating over it.
ex : ConcurrentHashMap, CopyOnWriteArrayList

If we use iterator inbuilt method remove() then the iterator will remove the element from the collection and it will not throw any exception.

-> Q. What is weak hashmap class in Java ?

WeakHashMap is a class where the keys which are no longer strongly referred by any other object are removed by garbage collector.
The keys which are not referenced those key value pair will be removed by garbage collector.

Map<Object, String> map = new WeakHashMap<>();
        Object key1 = new Object();
        Object key2 = new Object();

        map.put(key1, "Value1");
        map.put(key2, "Value2");

        System.out.println("Before GC: " + map);

        key1 = null;  // remove strong reference to key1
        System.gc();  // request garbage collection

        try { Thread.sleep(1000); } catch (InterruptedException e) {}

        System.out.println("After GC: " + map);
