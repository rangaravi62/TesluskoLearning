An even shorter version:

I would check data volume, indexes, execution plan, statistics, locks, and database load. Production may be slower because of larger data or a different execution plan even if the query is the same.

For an interview, this 6-point flow is easy to remember:

Data volume → Indexes → Execution plan → Statistics → Locks → DB load.
