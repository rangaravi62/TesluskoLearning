Custom Queries
-----------------------

We can use JPQL to write custom queries
JPQL doesn't support INSERT, it supports only SELECT, UPDATE and DELETE, so we need to use native query for INSERT


public interface IVaccineRepo extends JpaRepository<Vaccine,Integer> {

    @Query("FROM Vaccine WHERE vaccineCompany = :vaccineCompany")
    public List<Vaccine> searchByVaccineCompany(String vaccineCompany);

    @Query("FROM Vaccine WHERE vaccineName= :vc")
    public List<Vaccine> searchByVaccineName(@Param("vc") String vaccineName); // @Param because we are using the name different from the input parameter name (vaccineName)


    @Transactional
    @Modifying
    @Query("UPDATE Vaccine SET vaccineCost = :newPrice WHERE vaccineName = :vaccineName")
    public int updateVaccineInfo(Double newPrice, String vaccineName);

    @Transactional
    @Modifying
    @Query("DELETE Vaccine WHERE vaccineCost BETWEEN :minRange AND :maxRange")
    public int deleteVaccineBetween(Double minRange, Double maxRange);


    // JPQL doesn't support INSERT, it supports only SELECT, UPDATE and DELETE, so we need to use native query for INSERT
    @Transactional
    @Modifying
    @Query (value = "INSERT INTO VACCINE (vaccine_name, vaccine_company, vaccine_cost) values (:name, :company , :cost)", nativeQuery = true)
    public int insertVaccine(@Param("name") String name, @Param("company") String company, @Param("cost") Double cost);
}

------------------------------
What is JPA?-
------------------------------

JPA stands for Java Persistence API.

It is a specification that defines rules/annotations for ORM, like:
@Entity
@Id
@OneToMany
@ManyToOne
@Table
@Column

Hibernate is an implementation of JPA that performs the actual ORM operations

Spring Data JPA is built on top of JPA and provides repository abstractions to reduce boilerplate database code.


| Annotation        | Meaning                    |
| ----------------- | -------------------------- |
| `@Entity`         | Marks class as JPA entity  |
| `@Table`          | Maps class to table name   |
| `@Id`             | Primary key                |
| `@GeneratedValue` | Auto-generates primary key |
| `@Column`         | Maps field to column       |
